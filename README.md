## 01 — About

I've worked with data and design for more than 20 years, and for over 15 of them Excel has been at the center: databases, pivot tables, sales statistics and cash-flow models built for real businesses. I'm now taking that experience into Python, SQL and Linux, and this profile is where that new chapter lives.

**How I work**

- **Start from the real problem.** Understand the question before choosing the tool.
- **Analyze before concluding.** Look at the data first, then decide.
- **Build practical tools.** Less theory, more things that run.
- **Keep it simple and maintainable.** The smallest tool that solves the problem wins.
- **Learn in the open.** Experiments, documentation and independent projects.
